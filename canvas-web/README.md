# canvas-web

The infinite canvas, bundled into the app and loaded in WKWebView.

- `CanvasEngine` interface + engine-neutral Omnie object schema
- **Excalidraw** (MIT): Omnie embeddables (step, graph, source, quiz, world portal, atlas map), Canvas Agent, Mermaid → Excalidraw
- Spark.js splat viewer, MapLibre globe, KaTeX, Pyodide + SymPy worker

See docs/PLAN.md §3.3 and §9.
